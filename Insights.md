### What was new to me
F1: It was new to me to read form values with JavaScript instead of sending them to a server.
F2: It was new to me to build table rows with JavaScript instead of writing them in HTML.
F3: It was new to me that the look of an element can change depending on its value.
F4: It was new to me to remove one item from my data and update the page right away.
F5: It was new to me that data can be saved in the browser without a server.
F6: It was new to me to calculate statistics from my own data with JavaScript.
F7: It was new to me to filter data by date without reloading the page.
F8: It was new to me to draw a chart myself with SVG, without a library.


### New things I did learn
F1: I learned that event.preventDefault() stops the page from reloading when I submit the form.
F2: I learned to create elements with document.createElement() and to sort them by date with sort().
F3: I learned to add a CSS class like green, yellow or red with classList.add().
F4: I learned to remove an entry with filter() and to update everything with one render() function.
F5: I learned that localStorage only stores text, so I need JSON.stringify() and JSON.parse().
F6: I learned to calculate the average with reduce() and round it with toFixed(1).
F7: I learned that I can compare dates in JavaScript to show only the chosen period.
F8: I learned that the y-axis in SVG goes down, so high values need small y numbers.
